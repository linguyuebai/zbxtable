# 官方模式：本地后端直部署

这种方式保留官方 ZbxTable 的部署结构：后端 Go 程序直接提供嵌入式前端，不需要单独运行前端开发服务器，也不需要反向代理才能登录。

## Linux

在源码目录执行：

```bash
export ZBXTABLE_DB_TYPE=mysql
export ZBXTABLE_DB_HOST=127.0.0.1
export ZBXTABLE_DB_PORT=3306
export ZBXTABLE_DB_NAME=zbxtable_lg
export ZBXTABLE_DB_USER=zbxtable
export ZBXTABLE_DB_PASS='数据库密码'
export ZBXTABLE_HTTP_PORT=8089

sudo -E bash scripts/install.sh
sudo systemctl enable --now zbxtable
```

`scripts/install.sh` 会检查 Go 版本、数据库端口和数据库客户端；目标数据库不存在时自动创建 `zbxtable_lg`，然后编译后端。数据库账号需要具备创建数据库和该库建表权限。重复安装或修复时，脚本也会重新检查已有 `config/app.conf` 指向的数据库，避免服务注册成功后才发现目标库不存在。若数据库已经是 Zabbix 的 `zabbix` 库，脚本只使用现有库，不会删除或迁移 Zabbix 原生表。

如果出现 `cannot find GOROOT directory` 或 Go 版本低于 1.24，请先安装完整的 Go 1.24+ 工具链并确认 `go version` 正常；不要使用只有 `go.exe`、没有 `GOROOT/src` 的裁剪目录。

如果服务显示 `active (running)` 但端口无法访问，先查看真实退出原因：

```bash
sudo systemctl status zbxtable --no-pager --full
sudo journalctl -u zbxtable -n 120 --no-pager
sudo cat /usr/local/zbxtable/config/app.conf
sudo ss -ltnp | grep ':8089'
```

修复模式会保留已保存的配置，重新检查数据库，并把验证后的配置同步到 `/usr/local/zbxtable/config/app.conf`，避免旧运行时配置继续使用错误的端口或数据库地址：

```bash
curl -fsSL https://github.com/linguyuebai/zbxtable/releases/latest/download/install-release.sh | \
  sudo bash -s -- --repair --install-deps --install-root=/opt/zbxtable --port=8089
```

访问：

```text
http://服务器IP:8089/user/login
```

默认账号：`admin / Zbxtable`。登录请求由同一个后端提供：`POST /login` 和 `POST /v1/login` 均受支持。登录页、静态 JavaScript 和 API 必须使用同一个 `8089` 地址，不要再启动前端开发服务器或把请求转发到旧端口。

## systemd

Release 安装器会把后端复制到 `/usr/local/zbxtable`，生成 `zbxtable.service`，并以 `zbxtable` 用户运行：

```bash
curl -fsSL https://github.com/linguyuebai/zbxtable/releases/latest/download/install-release.sh | \
  sudo bash -s -- --install-deps --port=8089
sudo systemctl enable --now zbxtable
sudo systemctl status zbxtable --no-pager
```

服务的工作目录包含 `config/app.conf`，因此后端和嵌入式前端使用同一份配置与数据库。安装器不会停止、修改或删除 `zabbix-server`、`zabbix-agent` 或 Zabbix 数据库。

## 验证

```bash
curl -i http://127.0.0.1:8089/user/login
curl -i -X POST http://127.0.0.1:8089/v1/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Zbxtable"}'
curl -i http://127.0.0.1:8089/install/status
```

页面返回 `text/html`，登录返回 `application/json`；如果登录返回 HTML，通常是旧反向代理或旧浏览器 Service Worker 缓存，应清除站点缓存并确认请求地址为同一端口的 `/login` 或 `/v1/login`。
